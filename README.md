# DDR-Pad-with-Arduino-4-to-8-FSR-GUI
A high-performance DIY arcade dance pad built on a solid MDF frame, featuring 3D-printed PETG brackets and custom polycarbonate panels. Driven by an Arduino Pro Micro (1000Hz HID), it uses 8 FSR sensors in a parallel circuit with hardware RC filters to wipe out latency and electrical noise. The ultimate stamina build at a smart price!
